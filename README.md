# OmniFi · 万物金融 — The Periodic Table of Financialization

Every fundamental dimension of reality — matter, information, energy, time, spacetime, biology, culture, image, identity — has a unit of account. Every unit of account becomes a market. This is the map.

## Nine Elements

| # | Symbol | Element | Dimension | Unit |
|---|--------|---------|-----------|------|
| 01 | Pf | Payfi | Matter | USD / commodity |
| 02 | If | Infofi | Information | Token / bit |
| 03 | Ef | Enerfi | Energy | kWh / joule |
| 04 | Cf | Chronofi | Time | Second / block-time |
| 05 | Sf | Spacetimefi | Spacetime | Coordinate-bubble |
| 06 | Bf | Biofi | Biology | ATP / carbon / DNA |
| 07 | Cu | Cultufi · Ethnofi | Culture | Meme-attention |
| 08 | Vf | Visufi | Image | Pixel-attention |
| 09 | In | Iconofi | Identity | Recognition |
